# 写作风格指南与平台适配

## 一、核心写法体系

### 1. 白描/朴素写法（推荐）

**核心原则**
- 能用动词说清的，绝不用形容词
- 能用名词说清的，绝不用修饰语
- 情绪不直接说，用动作、生理反应、对话留白体现
- 句子短，形容词少，情感藏在事里

**参考作家**：余华《活着》、王朔《动物凶猛》、刘震云《一句顶一万句》、双雪涛《平原上的摩西》

**正面示范**
- 好："他蹲在墙根，把烟屁股在地上捻灭，又点了一根。"
- 坏："他孤独地蹲在冰冷的墙根，忧郁地把燃尽的烟屁股在粗糙的地上用力捻灭，又颤抖着点燃了一根新的香烟。"

**适用场景**
- 悬疑、现实题材、文艺向作品
- 需要强烈代入感和真实感的故事
- 第一人称叙事

**平台适配**：知乎盐选（最适配）、起点（文学向）、番茄（悬疑分类可配合快节奏使用）

---

### 2. 爽文写法

**核心原则**
- 主角强势，打脸频繁，升级快速
- 每300字一个情绪点（反转/冲突升级/新信息/关系位移）
- 情绪宣泄直接，读者代入感强
- 开篇前300字必须有冲突/悬念/反常

**正面示范**
- 好："他把合同拍在桌上：'这项目，我接了。但有个条件——你，滚出这个会议室。'"
- 坏："他感到非常愤怒，内心充满了不屈的斗志，决定要好好教训一下这些看不起他的人。"

**适用场景**
- 都市、玄幻、重生、系统、逆袭题材
- 需要快速抓住读者的碎片化阅读场景

**平台适配**：番茄（最适配）、七猫、书旗

---

### 3. 悬疑写法

**核心原则**
- 悬念密集，信息差控制精准
- 反转频繁，平均每3000字一个误导/反转
- 第一人称，带身体感和即时反应
- 从日常里长出的毛骨悚然（生活化悬疑）

**正面示范**
- 好："我翻出手机，凌晨1:17，订单已签收。签收人：无。我没点过确认。"
- 坏："我感到一阵深深的恐惧涌上心头，这件事情实在是太诡异了，让我不寒而栗。"

**适用场景**
- 悬疑、惊悚、推理、灵异题材
- 短篇故事（4000-30000字）

**平台适配**：知乎盐选（最适配）、番茄（悬疑分类）、黑岩

---

### 4. 情感写法

**核心原则**
- 细腻心理描写，关系拉扯
- 情绪共鸣，读者可代入的具体利害关系
- 对话有潜台词，有省略，有沉默
- 避免直接说情绪，用场景和动作体现

**正面示范**
- 好："她把碗推到我面前，筷子摆得整整齐齐，没说话。我盯着那碗面，热气模糊了眼睛。"
- 坏："她感到非常感动，内心充满了温暖和幸福，眼泪情不自禁地流了下来。"

**适用场景**
- 言情、家庭伦理、都市情感
- 女性向作品

**平台适配**：七猫、晋江、知乎盐选（情感反转类）

---

### 5. 宏大叙事写法

**核心原则**
- 世界观完整，设定缜密
- 群像塑造，人物成长弧光清晰
- 伏笔精巧，三层交叉（全书级/卷级/章节级）
- 允许铺垫，节奏可以慢热但必须有回报

**正面示范**
- 好："北境的雪下了三个月，斥候传回的军报堆了半尺高。大将军坐在帐中，手指在地图上划过三个地名。"
- 坏："这是一个非常宏大的世界，有着复杂的政治格局和激烈的权力斗争，大将军感到肩上的担子无比沉重。"

**适用场景**
- 玄幻、仙侠、科幻、历史题材
- 长篇作品（百万字以上）

**平台适配**：起点（最适配）、纵横、17K

## 二、平台适配详解

### 番茄小说

**读者画像**
- 下沉市场为主，三线及以下城市占比超51%
- 年龄跨度大：初中生到退休大爷
- 碎片化阅读，新书平均阅读时长不到30秒

**风格要求**
- 快节奏、强反转、高爽感，"电子榨菜"
- 语言简洁，段落短小，每句都没有废话
- 前三章必须让主角爽起来，不能受气
- 完读率是命门

**推荐写法**：爽文写法为主，悬疑写法可配合使用
**朴素写法适配度**：中等。可用于悬疑分类，但必须配合密集的剧情点和爽点，纯文学性朴素写法节奏太慢。

**题材偏好**：系统、穿越、脑洞、逆袭、神豪、战神、重生复仇、悬疑大逃杀

---

### 七猫小说

**读者画像**
- 与番茄类似，下沉市场为主
- 女性读者占比略高

**风格要求**
- 现言甜宠、古言重生、家庭伦理为主
- 高完读率，情感细腻但节奏要快
- 前10万字有专属流量扶持

**推荐写法**：情感写法为主，爽文写法配合
**朴素写法适配度**：中等偏低。情感描写需要细腻，但节奏也要快，纯朴素写法可能不够甜。

**题材偏好**：现言甜宠、古言重生、家庭伦理、萌宝、虐恋

---

### 起点中文网

**读者画像**
- 一二线城市为主
- 70%以上有三年以上阅读经验的老书虫
- 付费意愿强，长线追更耐心足

**风格要求**
- 世界观架构完整，人物成长逻辑清晰
- 情节推进缜密，伏笔精巧
- 允许铺垫，欣赏文字功力
- 传统题材中注入新颖设定与思辨内核

**推荐写法**：宏大叙事写法为主，白描/朴素写法可用于文学向作品
**朴素写法适配度**：高。起点读者有耐心，欣赏文字功力，朴素白描可以体现文学性。但需要配合宏大的世界观和复杂的剧情。

**题材偏好**：玄幻、仙侠、科幻、历史、都市、游戏

---

### 知乎盐选（盐言故事）

**读者画像**
- 一二线城市，高学历
- 喜欢烧脑、反转、真实感强的故事
- 付费意愿强，单篇稿费无上限

**风格要求**
- 第一人称视角，亲历式叙事
- 真实感强，生活化悬疑
- 强人设，快节奏，高情绪密度
- 前三段立"有刺"人设，每800-1200字必推进剧情
- 开头三句定调：倒计时/压迫感/非常规动作
- 留白式收束，去戏剧化叙述

**推荐写法**：白描/朴素写法（最适配）、悬疑写法
**朴素写法适配度**：非常高。知乎盐选本身就推崇第一人称纪实白描，去戏剧化叙述，留白式收束。朴素写法几乎是盐选的标配。

**题材偏好**：悬疑、社会热点改编、情感反转、生活化惊悚、职业揭秘

## 三、写法选择决策树

```
开始
  │
  ├─ 目标平台是知乎盐选？
  │   └─ 是 → 白描/朴素写法 + 悬疑写法
  │
  ├─ 目标平台是番茄/七猫？
  │   ├─ 是 → 爽文写法为主
  │   │       ├─ 悬疑题材 → 加悬疑写法
  │   │       └─ 言情题材 → 加情感写法
  │   └─ 否 → 继续
  │
  ├─ 目标平台是起点？
  │   ├─ 是 → 宏大叙事写法为主
  │   │       ├─ 文学向 → 加白描/朴素写法
  │   │       └─ 爽文向 → 加爽文写法
  │   └─ 否 → 继续
  │
  └─ 不确定平台？
      └─ 根据题材选择：
          ├─ 悬疑/现实 → 白描/朴素写法
          ├─ 都市/重生 → 爽文写法
          ├─ 言情/家庭 → 情感写法
          └─ 玄幻/科幻 → 宏大叙事写法
```

## 四、写法组合技巧

### 1. 白描 + 悬疑（知乎盐选黄金组合）
- 用朴素文字描写日常场景
- 在日常细节中埋藏诡异线索
- 情绪通过身体反应体现，不直接说
- 结尾留白，不解释全部

### 2. 爽文 + 白描（番茄悬疑分类）
- 剧情节奏快，爽点密集
- 但文字用白描，减少形容词堆砌
- 打脸场景用动作和对话体现，不用心理描写
- 适合悬疑、都市题材

### 3. 宏大叙事 + 白描（起点文学向）
- 世界观宏大，剧情复杂
- 但文字克制，用白描体现文学性
- 大场面用具体细节，不用形容词堆砌
- 适合历史、科幻、现实题材

### 4. 情感 + 白描（七猫/晋江）
- 情感细腻，关系拉扯
- 但不直接说情绪，用场景和动作体现
- 对话有潜台词，有留白
- 适合言情、家庭伦理

## 五、去AI感通用规则（所有写法适用）

### 禁止
1. 形容词堆砌：一个名词前最多1个形容词，禁止"冰冷的/孤独的/无尽的/深邃的/璀璨的"等无信息量修饰词连用
2. AI高频词：仿佛/似乎/感到/觉得/不由得/情不自禁/内心充满了/油然而生/涌上心头
3. 机械比喻："像一把刀""像一盆冷水""如同行尸走肉"
4. 解释过度：用行动体现情绪和动机，不直接说"他很难过因为..."
5. 排比句滥用："他想到了A，想到了B，想到了C"
6. 刻意感官描写："凉意贴着皮肤往上爬""炸开一朵光""过电似的传到手腕""心跳漏了一拍""喉咙发紧""手心冒汗"——冷就说冷，疼就说疼，用直白动作代替
7. 拟人化比喻："回音吞掉了尾音""风声绕了道""黑暗吞噬了一切""时间飞逝"——非人事物做人才有的动作
8. 套路化表达："记忆清晰得像刚发生的事""不像梦""那一刻我突然明白""时间仿佛静止""眼中闪过一丝复杂"
9. 情绪外化："空气沉下去""压在肩膀上""没怎么用力却让我..."——用具体场景和人物动作体现氛围

### 鼓励
1. 白描优先：动词、名词为主，少形容词
2. 动作体现情绪：攥拳、低头、沉默、转身、抽烟、踱步
3. 真实生理反应：但避免套路化（不用"心跳漏了一拍"，可用"心一紧""心里咯噔一下"）
4. 对话留白：有省略、有沉默、有答非所问
5. 具体数字锚点："二十三块""还剩十四分钟""第三十七根雨丝"
6. 不完美细节：指甲缝黑泥、扣子没扣、路灯闪烁、鞋边磨破
7. 段落长短交错：有呼吸感，紧张处用碎短句
8. 具体胜过抽象：不说"他很愤怒"，说"他把杯子摔在地上，碎片溅了一地"
