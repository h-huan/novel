# 平台独有风格系统

## 目标

平台学习公开作品的结构规律，同时保持故事、人物、设定和文字原创。它不把“每三章一个爽点”或“每固定字数一个反转”当作硬规则，而是根据平台、题材、篇幅、章节职责和当前张力选择节拍。

这些样本支持以下归纳：标题可以用身份反差、能力承诺、核心困境、意象悬念或人物口吻；开篇要尽快建立阅读承诺，但不必立即完成打脸；章节可以通过新信息、选择、代价、关系变化、压力升级、伏笔回收、情绪落点或阶段兑现产生价值；长篇需要张弛和滚动规划，不能把单一短周期公式复制几百次。

## 平台风格指纹

每个平台按题材和篇幅维护版本化指纹：

- 标题策略：标题结构、承诺类型、信息密度和题材匹配。
- 开篇策略：异常、欲望、人物声音、现实限制或直接冲突。
- 章节推进：允许的推进价值类型及常见密度范围。
- 回报类型：胜利、发现、关系变化、能力展示、情绪释放、伏笔兑现等。
- 张力曲线：铺设、发现、施压、恢复、兑现、收束、余波。
- 章尾作用：非终章制造下一步理由；终章完成收束或留下不依赖续章的余韵。
- 原创边界：只保存来源和派生标签，不保存或注入大段作品原文。

## 自适应学习

平台只从有来源的人工标注样本和通过质量 Gate 的自身作品学习。修复策略同时记录成功率、耗时、token、回滚和新增问题；样本不足时使用基线，达到最低样本量后才调整优先级。任何自动归纳都保留版本和来源，并可回滚到上一版。

题材发现自动把近期历史作品编译为排除集，并按职业/生存环境、关系结构、压力来源、核心机制、时间结构、真相载体和结局代价比较差异。相同母题可以复用，具体机制、调查路径与反转不能只换名称；每个候选必须留下可核验的差异说明。

章节分工审查输出冲突任务、违规规则、保留目标和可执行替代方案。平台先确定性应用替代方案，再复审；只有替代方案仍未解决的部分才交给模型重规划。策略学习同时记录完全通过与问题减少比例，让有效修法在后续同类生成中前置。

长篇采用滚动窗口：全书保存核心承诺与终局方向，卷级保存阶段目标，只把最近章节细化到场景。已确认结果进入连续性账本，再决定下一窗口，避免一次生成数千章固定模板。
